# 🐘 Ganapati Bappa Morya — India Journey 🇮🇳

An interactive **Ganapati Bappa Morya** educational adventure game that takes players on a sacred journey across India through stories, quizzes, cultural landmarks, and celebrations.

## ✨ Features

- 🕉️ Cinematic Ganapati-themed introduction
- 🇮🇳 Interactive India journey map
- 🗺️ **10 city-based levels**
- 📖 Traditional Ganesha stories and facts
- 🧠 Interactive quizzes
- ⏱️ Timed quiz challenges
- ⭐ Level scoring and star rewards
- 🔓 Progressive city unlocking
- 💾 Automatic progress saving using browser `localStorage`
- 🎵 Background instrumental music
- 🔔 Sound effects
- 🖥️ Full-screen support
- 📱 Mobile-friendly responsive design
- 🎬 Cinematic 3D-style visual effects
- 🎉 Final victory celebration
- 🔄 Restart and reset-progress options

## 🏙️ Journey Route

The game takes the player through:

1. 🌊 Kanyakumari — Tamil Nadu
2. 🛕 Madurai — Tamil Nadu
3. 🛕 Tirupati — Andhra Pradesh
4. 🌊 Vijayawada — Andhra Pradesh
5. 🏛️ Hyderabad — Telangana
6. 🌅 Bhopal — Madhya Pradesh
7. 🌊 Mumbai — Maharashtra
8. 🕌 Agra — Uttar Pradesh
9. 🇮🇳 Delhi
10. 🏔️ Srinagar — Jammu & Kashmir

Each city has its own environment, story, questions, and cultural landmark theme.

## 🎮 How to Play

1. Open the game.
2. Click **START JOURNEY**.
3. Select an unlocked city on the India map.
4. Read the story for that chapter.
5. Click **BEGIN QUIZ**.
6. Answer the questions before the timer runs out.
7. Score enough correct answers to complete the level.
8. Earn stars and unlock the next city.
9. Complete all 10 levels.
10. 🎉 Celebrate your final **Ganapati Bappa Morya** victory!

## 🧠 Quiz System

Most levels contain **5 questions**.

The final Srinagar challenge contains **10 questions**.

Players need to reach the required score to complete a level. Completed levels award stars based on the player's performance.

## 💾 Progress Saving

The game automatically saves:

- Unlocked cities
- Completed levels
- Level scores
- Stars earned

Progress is stored locally in the browser using:

```text
localStorage
```

This means players can return to the game on the same browser and continue their journey.
